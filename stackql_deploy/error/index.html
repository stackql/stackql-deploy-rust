§Error Handling Module

This module provides custom error handling for the StackQL Deploy application. It defines a comprehensive AppError enum that encapsulates various error conditions the application may encounter. Implementations of standard traits like Display and Error are provided to allow seamless integration with Rust’s error handling ecosystem.

§Usage Example

use crate::error::AppError;

fn example_function() -> Result<(), AppError> {
    Err(AppError::BinaryNotFound)
}
