fn filter_stale_notices(

    seen: &mut HashSet<String>,
) -> Vec<Notice>
Expand description

Drop detail lines whose canonical signature was already surfaced earlier in the session. seen is mutated in place: every line that survives filtering is added so it counts as stale on subsequent queries. A notice whose message is stale and whose detail becomes empty after filtering is dropped entirely.
