Module errors

Fatal error detection for StackQL query execution.

Maintains a list of error patterns that indicate unrecoverable failures (network issues, auth failures, etc.) vs normal operational errors (404 not found) that the retry/statecheck logic can handle.

Constants§

FATAL_ERROR_PATTERNS 🔒
Error patterns that indicate a fatal, non-retryable failure.
NON_FATAL_OVERRIDES 🔒
Patterns that indicate a non-fatal error, even if a fatal pattern also matches. These take precedence over FATAL_ERROR_PATTERNS.
